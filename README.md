# 求和好 💗

一个单页趣味互动小网页：一个「求和好」的道歉页面，带有经典的「点击按钮会跑」的彩蛋交互。

## ✨ 特点

- 💌 **浪漫配色**：粉紫渐变背景 + 柔和阴影，温馨的求和好氛围
- 🏃 **经典彩蛋**：两个按钮 —— 一个诚心诚意，一个怎么也点不到（试试看！）
- 📱 **全屏居中布局**：任何屏幕尺寸下都居中展示
- 🪶 **零依赖单文件**：所有样式与脚本都在 `hehao.html` 一个文件里，双击即用

## 🚀 使用方式

直接用浏览器打开 `hehao.html` 即可，也可以把它发给那个需要和好的人 😄

## 🛠 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- 无任何外部依赖与构建步骤

## 📄 许可证

仅供学习娱乐使用。
